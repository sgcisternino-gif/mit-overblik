# Mit overblik

En dansk privatøkonomi-app, der kører i browseren og gemmer registreringer lokalt på brugerens enhed.

## GitHub Pages

Workflowet i `.github/workflows/deploy-pages.yml` udgiver den offentlige version fra `public/` til GitHub Pages, når der pushes til `main`. I repository settings skal Pages-kilden sættes til **GitHub Actions**.

Den offentlige demo starter uden personlige løn- eller boligoplysninger. Besøgendes posteringer bliver i deres egen browser og sendes ikke til dette repository eller en server. GitHub Pages-sitet er offentligt tilgængeligt.
